# Tugas Besar & Kuis UTS - Pemrograman Berorientasi Objek (PBO)

Lima studi kasus Java yang menerapkan konsep dasar OOP sampai integrasi Collection (ArrayList).

| Soal | Studi Kasus | Konsep Utama |
|------|-------------|--------------|
| 1 | Sistem Data Buku | Class & Object, Attribute, Constructor, Method void |
| 2 | Rental Sepeda | Encapsulation (private), this, Method non-void |
| 3 | Sistem Kafe | Constructor Overloading, Method dengan parameter |
| 4 | Pemeriksaan Klinik | ArrayList, Looping, Kalkulasi total |
| 5 | Tiket Bioskop | Integrasi penuh OOP + ArrayList + format output |

## Cara menjalankan
```bash
cd Soal1_Buku
javac *.java
java Main
```
Ulangi untuk folder Soal2 sampai Soal5.
